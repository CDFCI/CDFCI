标题：将接收缓冲复用与并行最终发送缓冲复制合并进 CDFCI MPI 稳定版

本版本在已验证的 buffered MPI 稳定版和稳定并行分片基础上，加入两项候选优化：保留接收缓冲的有效容量，避免每轮重复清空后初始化；按 rank-major/thread-minor 偏移将大消息的线程局部缓冲并行复制到最终通信缓冲，小消息保留串行路径。

正确性验证在 paracloud 的 Slurm 计算节点完成。作业 7640656 使用 4 节点、4 rank、每 rank 16 OpenMP 线程、HPC-X 2.7.0-gcc/GCC 12.2/UCX rc_mlx5。发送字节回归、接收复用 1/2 rank 回归、确定性 exact-z/波函数/候选顺序差分回归和 C₆H₆ 200 次数值核验全部通过。

同一作业内基线与合并版的 C₆H₆ 最终能量均为 -231.3402174774913078 Ha，x/z/K 和全局工作量一致。完整案例 Wall time 为 342.25→332.60 秒（−2.82%），solver 迭代时间为 197.58→189.18 秒（−4.25%），rank0 最大 RSS 为 22.34→16.07 GiB。该性能结果是单次固定布局观测，技术报告保留了通信等待和节点负载的限制。

前驱计算诊断没有进入生产版，仅保留为研究工具。origin 未修改，MPI/origin 既有语义差异未在本次对齐。

## 最新 C₆H₆ 复验

使用当前稳定版完成了两个新配置：64 节点×32线程（作业 7641258）和 128 节点×32线程（作业 7641259），均为 600 次、每 100 次报告，退出码 0:0。64 节点点完整 Wall time 为 197.210 s，rank0 迭代区间为 40.803 s；128 节点点分别为 204.880 s 和 35.689 s。两点规模和工作量一致，最终能量差约 1.31e-12 Ha，符合不同 rank 数归约顺序的浮点差异。完整分项与限制见技术报告第 11 节。

前驱计算尝试已记录在技术报告第 12 节。该方向完成了 N₂ NUMA 近似诊断，但 C₆H₆ 200 次配对受限时未完成；前驱诊断没有合并进生产版。
